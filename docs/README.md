# PocketWise Documentation

## Structure

- `changes/` — Change logs for each significant PR
- `architecture/` — Permanent architectural decisions and system design
- `architecture-risk-register.md` — Medium-term architecture risks
- `security-audit-*.md` — Security audit reports (dated and immutable)

## Conventions

- Change logs are named `YYYY-MM-DD-<description>.md` and live in `changes/`
- Architecture docs are updated only when permanent decisions change
- Security audits are dated once created and never modified retroactively
